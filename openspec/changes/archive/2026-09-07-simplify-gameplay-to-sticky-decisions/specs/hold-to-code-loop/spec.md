## REMOVED Requirements

### Requirement: A coding session exposes one deterministic current task
**Reason**: Direct coding and tasks are removed.
**Migration**: The active sticky backlog is the run's work surface.

### Requirement: Focus rewards attentive review
**Reason**: Focus is removed.
**Migration**: Use Stamina costs.

### Requirement: Coding honors workday and resource availability
**Reason**: Coding is no longer a player action.
**Migration**: Sticky choices honor run and resource availability.

### Requirement: The laptop presents current coding state
**Reason**: The laptop is a passive prop.
**Migration**: Present live state in stickies and the status rail.

### Requirement: Opening an interruption decision suspends AI work safely
**Reason**: AI work is removed and decisions are inline.
**Migration**: No migration is required.

### Requirement: Temporary tool disruptions modify AI work against game time
**Reason**: Coding disruptions are removed.
**Migration**: Add equivalent authored choice time.

### Requirement: Interruptions can disrupt Focus explicitly
**Reason**: Focus is removed.
**Migration**: Apply equivalent immediate Stamina loss.
